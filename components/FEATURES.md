# Feature Support Matrix

This document states, per family and detail level, which chamfers, fillets,
recesses, threads, and other features are modeled, whether they are analytic or
an approximation, the approximation controls, what is omitted, and which tests
and fixtures cover them.

A feature is listed as **analytic** only when the STEP contains the
corresponding surface (conical, spherical, toroidal, cylindrical, or planar) or
a real swept/lofted form. A sharp edge is never described as a chamfer.

## New kernel primitives

### `Profile2D::chamfer_vertices` / `Profile2D::fillet_vertices`

- 2D helpers on a simple polygon. `chamfer_vertices(profile, distance,
  angle_deg?, which~)` truncates selected vertices with a straight bevel;
  `fillet_vertices(profile, radius, segments~, which~)` rounds them with a
  circular arc tangent to both adjacent edges.
- Convex/concave classification respects the input winding; `All`,
  `ConvexOnly`, `ConcaveOnly`, and explicit `Indices` are supported.
- Validation: minimum edge lengths, radius/distance fit, no self-intersection,
  positive finite size. Failed operations return a typed `ProfileOpError`.
- Representation: a polyline of line/arc samples. The arc is sampled with the
  caller's `segments`; the deviation is the polygon chord error
  `r (1 - cos(pi / (2 segments)))`.
- Tests: `cad/profile-chamfer_wbtest.mbt` (area of a chamfered/filleted square,
  oversized rejection, convex-only selection, explicit indices, winding
  preservation, asymmetric angle).

### `RevolvedProfile` (solid of revolution)

- A chain of line and arc bands in the (r, z) half-plane, revolved about +Z.
- Compiled to one closed solid with **analytic** faces:
  - line at constant r → `CYLINDRICAL_SURFACE`;
  - slanted line → `CONICAL_SURFACE`;
  - radial line → `PLANE` disc/annulus;
  - arc centred on the axis → `SPHERICAL_SURFACE`;
  - arc centred off-axis → `TOROIDAL_SURFACE`.
- Full-period bands carry a real seam edge; arcs use a circle edge trimmed by
  its two vertices. Singular poles (cone apex, sphere pole) are represented
  analytically; OCCT's tessellator emits a zero-area facet there, which the STEP
  validator now excludes from the watertight edge count (see `VALIDATION.md`).
- Presets: `cylinder`, `frustum`, `cone`, `sphere`, `sphere_cap`; arbitrary
  chains via `RevolvedProfile::new`/`polyline`.
- Independent volumes (OCCT): sphere R5 523.599 mm³, cone R4h8 134.041 mm³,
  frustum 4→2h6 175.929 mm³, cylinder R5h8 628.319 mm³, ring 2..5h2
  131.947 mm³, torus R5r1 98.696 mm³, dome rim4h3 89.535 mm³. All match the
  closed-form values.
- Tests: `cad/revolved_profile_wbtest.mbt`; artifacts generated by
  `components/examples/revolution`.

### `ChamferedPrism` (ring-stack prism with an optional through-hole)

- A convex prism whose outer boundary is a stack of parallel-inset rings, with
  an optional prismatic through-hole. Consecutive rings are joined by planar
  ruled quads; the ends are planar caps (annular when a hole is present).
- Builders: `ChamferedPrism::new(base, levels, hole?)` and
  `from_chamfer(base, height, bottom_chamfer~, top_chamfer~, chamfer_depth~,
  hole?)`.
- Validation: base convex, increasing level z, positive insets that shrink the
  polygon, simple inset rings, valid hole.
- This is the vehicle for real chamfers on hex nuts, socket-head heads, and
  washers.
- Tests: `cad/chamfered_prism_wbtest.mbt`.

## Families

### ISO 4762 socket head cap screw

| Feature | Simplified | Detailed | FullyModeled |
|---|---|---|---|
| Plain/chamfered shank | plain cylinder | plain cylinder | minor core + swept helical ridge |
| Blind hex socket | hex through-hole ring over a floor disc | same, with 45° top-edge head chamfer | same (helical body) |
| Head top chamfer | omitted | **analytic-ish** (real ruled ring stack, planar facets) | omitted on the helical body |
| Thread | none | none | swept helical ridge (approximation) |

The head chamfer is a real, measurable ring-stack chamfer (a `ChamferedPrism`
socket ring), not a relabelled sharp edge. Its size is an engineering default
(`head_chamfer_mm`) because ISO 4762 does not fix it. Covered by
`fasteners_test.mbt` and the `iso4762-M4-detailed` fixture.

### ISO 4032 hexagon regular nut

| Feature | Simplified | Detailed | FullyModeled |
|---|---|---|---|
| Bore | cylindrical | cylindrical | major bore + swept internal ridge |
| Face chamfers | omitted | **real** ring-stack chamfer on both bearing faces | omitted on the helical body |

The face chamfer is an engineering default (`nut_chamfer_mm`), because ISO 4032
does not fix it. Its angle is stated as 45° in the component description.
Covered by `fasteners_test.mbt` and `iso4032-M4-detailed`.

### ISO 7380-1 button head hexagon socket screw (new)

| Feature | Simplified / Detailed / FullyModeled |
|---|---|
| Shank | plain cylinder (helical ridge at FullyModeled) |
| Head | spherical-cap dome (`SPHERICAL_SURFACE`) with a flat top |
| Socket | real hexagon through-hole in a high-resolution polygon socket band |
| Flat-top radius | engineering choice (`button_flat_radius`); not a standard dimension |
| Dome band (socket ring outer) | high-resolution polygon following the sphere |

Head diameter, head height, socket size, and socket depth are the standard's
nominal values. Covered by `fasteners_test.mbt` and `iso7380-M4x16-detailed`.

### ISO 10642 countersunk head hexagon socket screw (new)

| Feature | Simplified / Detailed / FullyModeled |
|---|---|
| Shank | plain cylinder (helical ridge at FullyModeled) |
| Head | **analytic** 90° countersink frustum (`CONICAL_SURFACE`), 45° half-angle |
| Socket | real hexagon through-hole in a polygon socket band over the analytic floor |
| Top face | flat annulus with the socket opening |

The head floor below the socket floor is analytic; the top socket band (about
the socket depth) is a high-resolution polygon. Covered by `fasteners_test.mbt`
and `iso10642-M4x16-detailed`.

### Bearings

| Feature | Simplified | Detailed / FullyModeled |
|---|---|---|
| Rings | plain tubes | ring stacks with an engineering-default edge chamfer |
| Rolling elements | **analytic spheres** (`SPHERICAL_SURFACE`) | analytic spheres |
| Bore chamfer / groove | omitted | omitted (hole not chamfered) |
| Seals / cage | omitted | omitted |

Ball diameter equals the modeled radial gap; it is envelope geometry, not a
catalogue value. Covered by `motion_test.mbt` and `motion-608-stack-detailed`.

### Shafts

| Feature | Plain / stepped shaft | Filleted stepped shaft |
|---|---|---|
| Body | stacked cylinders | one `RevolvedProfile` solid |
| Shoulder fillet | omitted | **analytic** toroidal fillet on increasing steps |
| Decreasing steps | sharp | sharp (fillet only where it fits) |

`filleted_stepped_shaft(segments, fillet_radius_mm~)` produces a single solid
with a real `TOROIDAL_SURFACE` fillet (measured major radius = shoulder radius
− fillet radius, minor radius = fillet radius). Covered by `motion_test.mbt` and
`filleted-shaft-d10-16.step`.

## Omitted features and approximations

- **Threads** remain swept helical ridges with the ISO 68-1 basic profile; they
  are not tolerance-class threads. `FullyModeled` only.
- **Socket bands** on the new heads and the head chamfers on the prisms are
  polygon approximations of the ideal surface; the facet count is the caller's
  `circle_segments` (64 at Detailed), and the deviation is the polygon chord
  error (well under 0.01 mm at that resolution).
- **ISO 7380** the head profile (spherical cap and flat-top radius) is an
  engineering approximation; only `dk`, `k`, `s`, `t` come from the standard.
- **Bearing chamfers and ball diameter** are engineering defaults from the
  boundary dimensions, not catalogue internal geometry.
- **Nominal STEP booleans** remain: the library still layers closed solids
  rather than trimming with `difference()`. Layered parts export as several
  watertight solids.

## Machine-readable feature records

Every `Component` carries a `FeatureRecord` (`components/common/features.mbt`):

- `modeled`: features represented by exact analytic surfaces or exact
  planar/ruled geometry.
- `approximated`: features with a stated `deviation_mm` and the generator
  `control` (for example `circle_segments=64`).
- `omitted`: features that are intentionally absent, each with a documented
  reason.
- `tolerance_mm`: the component's overall stated representation tolerance.

`Component::documentation()` appends the record to the STEP header, so a file
states what it models, approximates, and omits. Builders populate the record
for every family: ISO 4762/4032/7089/4014/4017/7380/10642, bearings, shafts,
spacers, keys, pins, standoffs, springs, extrusion profiles, gears, and the
assembly layer (which aggregates its instances). Tests assert representative
records (for example the detailed nut lists `nut-face-chamfer`, the simplified
nut omits it with a reason, and the bearing lists `ball-sphere`).

Detail levels are reflected in the record: `Simplified` omits small features
only when the record says so; `Detailed` lists every modeled chamfer/recess;
`FullyModeled` lists the swept thread (`helical-thread`) and its polyline
approximation (`helical-ridge`).

## Session additions (2026-11-10)

### Evaluated 3D edge fillet/chamfer (optional kernel path)

- `Shape::Fillet(EdgeFeature)` / `Shape::Chamfer(EdgeFeature)` carry a base
  solid, an `EdgeSelector` (`AllEdges`, `EdgesByDirection`, `EdgesNearPoint`,
  `EdgeIndices`), a size, and an optional chamfer angle.
- The flat STEP writer **refuses** these nodes with the typed
  `EdgeFeatureRequiresKernel` error diagnostic; it never emits the sharp base.
- `Design::to_step_evaluated()` writes the intent as a
  `MOONBIT_EDGE_FEATURE` node; `scripts/csg_eval.py` selects the edges and
  applies OCCT `blend` (fillet) or `chamf` (chamfer).
- OCCT tests confirm a cylinder's top-rim fillet produces a
  `TOROIDAL_SURFACE` and a chamfer produces a `CONICAL_SURFACE`; both pass the
  STEP validator. This path is optional and is not a runtime dependency.

### Gear root fillet and tip chamfer

- `external_involute_outline_ex()` applies `Profile2D::fillet_vertices` to the
  root corners and `Profile2D::chamfer_vertices` to the tooth tip corners.
- Root runs and tip runs are collapsed to their endpoints so the tangent arc
  has a usable edge; the root band widens adaptively when a high tooth count
  puts the root circle very close to the base circle. An operation that still
  does not fit returns a typed error (never a silently sharp root).
- The root fillet is a polyline arc sampled with `fillet_segments`; the chord
  deviation is `r(1-cos(pi/segments))` (0.054 mm at 6 segments for r = 0.4,
  below 0.01 mm at 24 segments). The filleted gear extrusion validates
  watertight.
- Feature records list `root-fillet` / `tip-chamfer` when present and omit them
  with a reason otherwise.

### Extrusion corner radii and series

- `TSlotProfile::with_corner_radius()` rounds the four outer section corners
  with the 2D fillet helper (`corner_segments=8`). The corner arc deviation is
  recorded. Independent OCCT measurement of a 1.5 mm-radius 2020 frame gives a
  post section area of 190.37 mm² (sharp generic envelope 192.345 mm² minus
  four rounded corners).
- Generic 2060, 2080, 3060, and 4080 envelopes were added and are labelled
  generic, not vendor-compatible.
- The generic 2020 envelope is **explicitly not** the manufacturer-specific
  B-slot6 section: its solid section area is 192.345 mm² versus the golden's
  measured 174.336 mm². A test encodes that discrepancy; no preset is derived
  from the unlicensed golden.

### Catalogue and query API

- New `components/catalog` package: `CatalogEntry` carries designation,
  standard, family, size, supported parameters, detail levels, the feature
  record, and provenance. `lookup` and `query` support designation/standard/
  family/size searches. The catalogue is built from the real component
  builders, so records cannot drift from generated geometry.

### Mixed-family assembly

- `assemblies::bolted_joint` places two plates, an ISO 4762 screw, an ISO 7089
  washer, and an ISO 4032 nut with explicit transforms. It is connected, has a
  deterministic bounding box, and its flat STEP has 7 watertight solids. The
  OBB collision reports the shank inside the plate/washer/nut bores as the
  documented nested-bore false positive.

### Deferred after evaluation

- **Exact internal involute ring gear.** An involute internal profile was
  implemented and checked over a rotation cycle; it produced 300+ tooth-outline
  crossings against the planet, so it was removed rather than shipped. The
  validated trapezoidal approximation is retained and the omission is recorded
  in the ring feature record. See `KNOWN_ISSUES.md`.
